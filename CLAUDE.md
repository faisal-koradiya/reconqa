# ReconQA — working rules

Public, explore-first, tool-agnostic QA plugin for Claude Code. Plan, phases and review notes: local/ (on this computer only, not in the repo).

- Clean room: never copy files, text, names, URLs, IDs, screenshots or numbers from any employer or client work (local paths in CLAUDE.local.md). Write everything fresh and generic.
- Examples use the public demo app and public/free tools only.
- Skills refer to capabilities (tracker, test-management, docs, comms, app), never to a tool name; tool specifics live only in `plugins/reconqa/adapters/`.
- Every write to an external tool goes through a dry run the user approves first.
- Do not commit until a personal git email is set in this repo (`git config user.email`).
