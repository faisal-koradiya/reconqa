# LOOP-12: Track habits with a number (fictional ticket for the ReconQA lab)

As a user I want habits I can measure (pages read, km run), not only yes/no habits.

Acceptance criteria:

1. Tapping "Add habit" lets me choose between a yes/no habit and a measurable habit.
2. The measurable form asks for Name, Question, Unit, Target, Frequency, Target Type, Reminder and Notes.
3. Target shows the hint "e.g. 10".
4. Target Type offers "At least", "Exactly" and "At most"; "At least" is the default.
5. Saving with an empty Name shows "Name is required".
6. Saving with an empty Target is refused with a message on the Target field.
7. Frequency starts at "Every day".
8. After saving, the app goes back to the habit list and the new habit is shown.
