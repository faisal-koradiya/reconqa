# Story: Smoother sign-up

*Fictional eval ticket (ReconQA knowledge-base eval).*

As a new visitor, I want signing up to take me straight into the shop.

## Acceptance criteria
1. After registering, the user is logged in automatically and sees the product list.
2. The user must accept the terms and conditions before registering.
3. If the email already has an account, the form shows "This email is already registered." under the email field.
4. The "Already a customer?" link takes the user back to the login page.
