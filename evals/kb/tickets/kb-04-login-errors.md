# Story: Helpful login errors

*Fictional eval ticket (ReconQA knowledge-base eval).*

As a customer, I want to know what went wrong when I can't log in.

## Acceptance criteria
1. If the password is wrong, the login page says "Your password is incorrect." and if the email is unknown it says "No account with this email."
2. The "Log in" button stays disabled until email and password are filled in.
3. Leaving the email field empty shows an error under it.
