# Story: Recurring bills as schedules

*Fictional ticket for the ReconQA second-app eval (Actual Budget). Written the way a product owner
might, with some details that don't match the app.*

As a budget user, I want to set up my recurring bills once so that I see them coming.

## Acceptance criteria
1. From the Schedules page, "Add new schedule" opens a dialog to create a schedule.
2. A schedule must have a name; the Add button stays disabled until a name is entered.
3. New schedules repeat by default (Repeats is checked).
4. The repeat can end "never", "after a number of times" or "on a date".
5. Bills can repeat every day, week, month or year.
6. "Automatically add transaction" is off by default.
7. The amount can be set as approximate, exact or a range; the approximate option is labelled "is about".
8. The schedule list shows a "Due date" column.
